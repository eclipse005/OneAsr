OneAsr macOS 安装说明
=================================

本窗口里有四个东西：
    安装 OneAsr.command    ← 安装用的脚本，下面两步都靠它
    OneAsr.app            ← 程序本体
    安装说明.txt           ← 本文件
    Applications          ← 「应用程序」文件夹的快捷方式

安装：先试方式一，被拦了就换方式二
----------------------------------

方式一 · 右键打开（先试这个）

    1. 右键点「安装 OneAsr.command」（或按住 Control 单击）
    2. 菜单里选「打开」，弹出的框里再点一次「打开」
    3. 它会自动装好并启动 OneAsr，最后弹一个「搞定」的提示

    注意：不要点「移到废纸篓」 —— 那是把脚本删掉。
    注意：如果弹框里只有「完成」、根本没有「打开」，或者提示
          「Apple 无法验证…是否包含恶意软件」，说明这台 Mac 的系统
          版本（macOS 15 起）把这条路封了 —— 直接去做方式二，
          别去「系统设置 → 隐私与安全性」里找「仍要打开」，那里对
          脚本不生效。

方式二 · 用终端运行（最稳，任何版本都能用）

    1. 打开「终端」：按 Command + 空格，输入「终端」或 Terminal，回车
    2. 在终端里敲四个字符：   bash
       注意 bash 后面要留一个空格，先别回车
    3. 把「安装 OneAsr.command」图标从这个窗口拖进终端窗口，
       路径会自动补上（这是为了不用手打路径）
    4. 回车

    之后它会自动装好并启动 OneAsr，最后弹一个「搞定」的提示。

    如果你更想手动打字，路径大概是（卷名以你看到的为准，
    不确定就先在终端里敲 ls /Volumes 看一眼）：

        bash "/Volumes/OneAsr 1.0.3/安装 OneAsr.command"

脚本到底做了什么
----------------
1. 把 OneAsr.app 复制进「应用程序」文件夹（已存在就覆盖重装）
2. 清掉 macOS 给下载文件打的隔离标记
3. 给 App 补一个本机临时签名
4. 启动 OneAsr

需要写「应用程序」文件夹时才会弹一次管理员密码。

为什么会被拦（文件本身没坏）
----------------------------
OneAsr 目前没有 Apple 开发者签名（开发者账号一年 99 美元）。浏览器下载
下来的文件会被 macOS 打上隔离标记，直接打开会报下面这类话：

    「OneAsr」已损坏，无法打开。你应该将它移到废纸篓。
    Apple 无法验证「…」是否包含可能危害 Mac 安全或泄漏隐私的恶意软件。

文件是好的，这是误报。上面两种方式做的事一样，就是替你把标记清掉。
装好一次之后，以后打开都不会再拦。

完全手动（脚本也不想用时）
--------------------------
1. 把 OneAsr 拖进「应用程序」文件夹
2. 打开「终端」，粘贴执行下面两行（要密码就在前面加 sudo）：

       xattr -cr /Applications/OneAsr.app
       codesign --force --deep --sign - /Applications/OneAsr.app

3. 回到「应用程序」文件夹双击 OneAsr

首次运行
--------
第一次启动会下载语音识别模型（几百 MB 起，取决于网速），界面里有进度，
下完就能离线使用。识别全程在本机进行，不上传任何音视频。

安装完成后就可以把这个磁盘映像推出了。
