# OneAsr 1.2.1 — subtitle lines that end where sentences end

Smart break now uses the same line-breaking logic as transcription, and the task list stops re-scanning your whole transcript on every frame.

## Fixed

- **Smart break cuts on sentence boundaries.** It used to split purely on a character count, so a line of Chinese dialogue came back chopped mid-sentence — 82% of the breaks landed inside a sentence in our test material. It now breaks at the same punctuation the transcription path does; the same material drops to 3%. Your text is still untouched: only line breaks change, never a character.
- **Smart break no longer freezes the window.** Splitting a long script takes a moment; it used to run on the UI thread, so the window stopped responding and animations stalled. It runs in the background now, and clicking it again while it works no longer starts a second pass.
- **Long task lists repaint faster.** Every redraw re-read each attached transcript to count its lines, characters and speech rate. Those numbers are computed once and reused, which shows most when many long scripts are queued.
- **The aligning progress bar in transcript matching is now truthful.** It used to count windows as they were queued, so it sat at 100% while a fifth of the work was still running on the GPU. It now counts the whole job — encoding, the Viterbi pass, traceback, score replay and the timeline — and only reaches 100% when the last of those is done.
- **Closing the window stops the background timer.** A 80 ms polling loop kept running after the last window closed until the process exited.

# OneAsr 1.2.1 — 断在句末，而不是断在字数

智能断句改用与语音识别同一套断句逻辑，任务列表也不再每一帧重扫整份文稿。

## 修复

- **智能断句断在句子边界。** 以前只按字数切，一整行中文对白会被从中间劈开——实测素材里 82% 的断点落在句中；现在与识别断句一样在标点处断开，同一份素材降到 3%。你的字仍然一个不动：只改换行。
- **智能断句不再卡住窗口。** 长文稿断句要花一点时间，以前跑在界面线程上，窗口会没反应、动画会停；现在放到后台，期间再点也不会重复跑一遍。
- **长任务列表重绘更快。** 以前每次重绘都要把每份挂着的文稿重新读一遍来算行数、字数与语速；现在只算一次就复用，排队的长文稿越多越明显。
- **文稿匹配的打轴进度条现在说真话了。** 以前按「窗口已提交」计数，所以活还挂在显卡上时条已经停在 100%；现在数的是整条作业（编码、Viterbi、回溯、分数回放、时间线），只有最后一步也做完了才到 100%。
- **关闭窗口后后台定时器停止。** 最后一个窗口关掉之后，那个 80 毫秒的轮询循环还会一直空转到进程退出。
