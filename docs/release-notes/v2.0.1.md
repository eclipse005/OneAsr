# OneAsr 2.0.1 — Electron UI polish

> **Preview build** — continues the Electron line after 2.0.0 and is marked as a pre-release on GitHub. The stable GPUI release remains available on the releases page.

This patch keeps the Electron interface and offline engine from 2.0.0, and focuses on interface polish, accessibility, and a few task-flow fixes.

## New

- **Shared UI building blocks**: spacing, color and type now come from design tokens; common controls (toggles, segmented controls, icon buttons, dialogs) reuse the same primitives, so Settings, panels and dialogs look consistent.
- **Motion**: panel opens, dialogs and the guide use the same Framer Motion curves and short micro-interactions instead of mixed timings.
- **Sounds**: click and reminder sounds are wired to the Settings toggle; the completion sound behaviour is unchanged.
- **Guide**: the first-run / Guide walkthrough is shorter (about six steps) with clearer medium-length copy, and several placement / Esc / tab-click blockers are fixed.

## Fixed

- **Welcome screen**: the colored placeholder is replaced with the OneAsr logo.
- **Titlebar (Windows)**: window controls use a transparent overlay with env safe-area insets, so the titlebar no longer fights the system buttons.
- **Dialogs**: ModalShell traps keyboard focus while open (accessibility), so Tab stays inside the dialog.
- **Settings labels**: section and field label weights match across General / Models / System / Output.
- **Cancel a queued or running task**: the row returns to Pending instead of sticking on Cancelled; only a toast is shown, and Start works again on that row.
- **i18n**: language options localise the Auto label with the rest of the UI.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 2.0.1/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 2.0.1 — Electron 界面打磨

> **预览版** —— 接续 2.0.0 的 Electron 线，在 GitHub 上标记为预发布（pre-release）。稳定的 GPUI 正式版仍可在 Releases 页面下载。

这一版保持 2.0.0 的 Electron 界面与离线引擎，主要做界面打磨、无障碍与几处任务流程修复。

## 新增

- **统一的界面基础件**：间距、颜色与字号走 design token；开关、分段控件、图标按钮、对话框等共用同一套基础组件，设置、面板与弹窗观感一致。
- **动效**：面板打开、对话框与引导共用同一套 Framer Motion 曲线和短微交互，不再各写一套时长。
- **提示音**：点击音与提醒音已接到设置开关；完成音行为不变。
- **引导**：首启 / 指南里的 walkthrough 压缩到约六步，文案改成中等长度，并修了若干定位、Esc、设置页签点击等卡点。

## 修复

- **欢迎页**：色块占位换成 OneAsr logo。
- **标题栏（Windows）**：窗口控件改为透明 overlay，并用 env 安全区，不再与系统按钮抢空间。
- **对话框**：ModalShell 打开时会困住键盘焦点（无障碍），Tab 不会跑到对话框外。
- **设置标签**：各分区与字段标签字重统一。
- **取消排队或运行中的任务**：行状态回到「待处理」，不再粘在「已取消」；只出 toast，该行可以再次开始。
- **国际化**：语言选项里的 Auto 与界面其它文案一起本地化。

## macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 用终端运行 —— 任何 macOS 版本都能用的方式：

```bash
bash "/Volumes/OneAsr 2.0.1/安装 OneAsr.command"
```

2. 想在访达里操作，就右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
