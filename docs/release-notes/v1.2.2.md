# OneAsr 1.2.2 — 错误日志聚焦问题排查

## 新增

- 正常启动和成功任务的过程信息不再写入错误日志。转写失败或进程在任务中退出时会记录任务上下文与阶段耗时，Rust panic 记录也会附带调用回溯。
