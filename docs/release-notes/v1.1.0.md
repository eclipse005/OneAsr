# OneAsr 1.1.0 — local, offline audio/video → subtitles

This release adds **int8 quantized models** and reworks the download experience in Settings.

## New

- **int8 quantized models**: 0.6B and 1.7B each gain a quantized variant with smaller weights and a lower VRAM footprint (0.6B: 1.56 GB → 1.13 GB; 1.7B: 4.08 GB → 2.67 GB), which suits machines short on VRAM. A new **Quantization** button next to "0.6B / 1.7B" in Settings toggles it in one click; the model downloads from the built-in mirror and its files are verified exactly like the regular ones.
- **A model folder per size**: 0.6B, 1.7B and the two quantized variants each remember their own model folder, so switching sizes no longer overwrites the others and a hand-picked path is never lost.
- **Download progress inside the model card**: while downloading, the path row turns into a progress display (percentage + live speed) and becomes the path again when the download finishes; several models downloading at once each show their own progress without interfering.
- **Re-download looks before it leaps**: "Re-download" first checks whether the local files are complete — if they are, it just says so and leaves the UI untouched instead of downloading again; the download starts only when files really are missing or corrupted.
- **Unified settings controls**: the sound option became a slider; vocal separation became an "On by default" toggle (its ready state moved to the card's top-right corner, so all three model cards now look alike); "Output format | Chinese script" split the width evenly.
- **Model path and download button share one row**, the path stays on a single line with the full path on hover, making the card more compact.
- **Wider settings drawer**: the drawer grew from 400px to 450px, block spacing is even, and the last item no longer sits against the bottom.
- **Unified button styling**: Clear / Reset and the other buttons are now bordered like the rest; Clear keeps its red warning tint and fills with solid color on hover.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.1.0/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 1.1.0 — 本地离线音视频转字幕

这一版新增 **int8 量化模型** 支持，并把设置里的下载体验重新梳理了一遍。

## 新增

- **int8 量化模型**：0.6B 和 1.7B 各多了一个量化档，权重体积更小、常驻显存更少（0.6B 权重 1.56 GB → 1.13 GB，1.7B 4.08 GB → 2.67 GB），适合显存偏紧的机器。设置里「0.6B / 1.7B」旁边新增「量化」按钮，点亮即切换，可以直接从内置仓库下载，文件校验方式与普通模型完全一致。
- **四个模型目录各自记忆**：0.6B / 1.7B 和两个量化档各记各的模型目录，切换档位时互不覆盖，手动选过的路径不会再丢。
- **下载进度显示在模型卡片里**：下载中，路径栏原位变成进度显示（百分比 + 实时速度），下载完成自动变回路径；多个模型同时下载时各自独立显示、互不干扰。
- **重新下载先验货**：点「重新下载」会先检查本地文件是否完整，完整时只提示一句、界面保持不动，不再重复下载；文件确实缺失或损坏时才进入下载。
- **设置控件统一**：提示音改为滑动开关；人声分离改为「默认启用」点亮按钮（就绪状态点回到卡片右上角，三张模型卡样式一致）；「输出格式 | 中文输出」两列平分宽度。
- **模型路径与下载按钮合并成一行**，路径单行显示、悬停可看完整路径，卡片更紧凑。
- **抽屉加宽**：设置抽屉从 400px 加宽到 450px，各设置块间距统一，最后一项不再贴着底部。
- **按钮样式统一**：清空 / 重置等按钮与其它按钮一样带边框，清空保留红色警示，悬停时填充实色。

1. 用终端运行 —— 任何 macOS 版本都能用的方式：


2. 想在访达里操作，就右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
