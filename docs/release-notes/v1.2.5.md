# OneAsr 1.2.5 — close to tray, transcribe-only TXT, a smarter aligner dot

## New

- **Close to tray**: a new Settings toggle decides what the window close button does. On, closing hides the window to the tray and a running task keeps going; off keeps the old behaviour — closing quits the app. The tray icon stays resident and its menu offers Open / Quit; Quit always really quits, whatever the toggle says (issue #18).
- **Transcribe only**: tick TXT alone (no SRT / ASS) and the run stops at transcription — one sentence per line, cut on sentence punctuation. A task that only needs text no longer needs an aligner model at all (issue #19).
- **The "Aligner model" dot follows the output format**: green when the selected aligner is ready, red when it is missing, and gray when only TXT is selected — nothing to align, so nothing to warn about. Transcribing always needs the ASR model, so its dot stays green / red.
- **CLI `--asr`**: name the recognition model explicitly — `--asr 0.6b` / `--asr 1.7b`, or a full directory name such as `Qwen3-ASR-1.7B-int8`. A size takes that size's fp16 or int8 form (fp16 first); a directory name is taken literally. Without the flag the installed models are scanned as before.

## Fixed

- **Linux**: closing the window while a task was running could panic on X11. The quit path is now asynchronous, matching Windows and macOS.
- **CLI `--asr`**: `--asr 1.7b` now also finds an installed 1.7B int8 variant instead of reporting the model missing when only the quantized weights are on disk; and a model you name explicitly is never silently swapped for a different installed one.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.2.5/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 1.2.5 — 关窗到托盘、仅转写、对齐模型指示灯

## 新增

- **关窗到托盘**：设置里新增一个开关决定窗口关闭按钮的行为。开启时关窗收进系统托盘，正在跑的任务不中断；关闭时维持原语义——关窗即退出。托盘常驻，菜单提供「打开 / 退出」；「退出」永远真退出，不受开关影响（issue #18）。
- **仅转写**：只勾 TXT、不勾 SRT / ASS 时，任务转到转写为止——一行一句，按句末标点断句。只需要文字的任务从此完全不需要对齐模型（issue #19）。
- **「对齐模型」指示灯跟随输出格式**：所选对齐模型就绪时绿、缺失时红；只勾 TXT 时变灰——没有东西要对齐，也就没什么可提醒的。转写永远需要 ASR 模型，所以它那颗灯仍是绿 / 红。
- **命令行新增 `--asr`**：显式点明识别模型——`--asr 0.6b` / `--asr 1.7b`，或写完整目录名（如 `Qwen3-ASR-1.7B-int8`）。给尺寸时用该尺寸的 fp16 或 int8 变体（fp16 优先）；给目录名时只认它自己。不带该旗标时仍按原样扫描已装模型。

## 修复

- **Linux**：任务运行时关窗在 X11 上可能崩溃。退出路径改为异步，与 Windows / macOS 一致。
- **命令行 `--asr`**：机器上只装了 1.7B 的量化权重时，`--asr 1.7b` 现在能找到它，而不是报「模型缺失」；点名了具体模型时也绝不悄悄换成另一个已装的。

## macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 用终端运行 —— 任何 macOS 版本都能用的方式：

```bash
bash "/Volumes/OneAsr 1.2.5/安装 OneAsr.command"
```

2. 想在访达里操作，就右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
