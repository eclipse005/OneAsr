# OneAsr 1.5.0 — Qwen3-ForcedAligner-Ultra is the default aligner

## New

- **Qwen3-ForcedAligner-Ultra by default**: the Qwen aligner option now uses the Ultra fine-tune and the Local Head shipped with it. Boundaries are refined from the model's 80 ms timestamp grid to 10 ms. CTC remains available in Settings, and transcript matching still uses CTC.
- **The aligner has a new name and folder**: it now downloads as `Qwen3-ForcedAligner-Ultra`. Existing `settings.json` selections and per-model directories written under `Qwen3-ForcedAligner-0.6B-hf` are migrated automatically; the old folder is no longer used, and the Ultra weights download the first time you align (about 1.8 GB).
- **Long queues stay smooth**: the task list is virtualized and draws its own scrollbar, so finished tasks no longer add a widget for every row.
- **Successful tasks keep a log**: a completed task retains a rolling log without adding noise to the task row, so a problem can still be investigated after the fact.
- **Blind VAD cuts at the quietest point**: when no pause is long enough, the cut now lands on the lowest-energy point instead of an arbitrary frame; the pause threshold is 1 ms.

## Fixed

- **Transcript polish handles semicolons**: a semicolon is collapsed to a single space like the other sentence punctuation.
- **Model download progress no longer starts at 100% when replacing a model**: a previous checkpoint with a different size is not counted as downloaded bytes, so the bar reflects the download in progress.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.5.0/安装 OneAsr.command"
```

2. Or right-click 安装 OneAsr.command → "Open" → "Open" again in the dialog.

# OneAsr 1.5.0 — 默认改用 Qwen3-ForcedAligner-Ultra

## 新增

- **默认对齐器改为 Qwen3-ForcedAligner-Ultra**：Qwen 选项改用 Ultra 微调模型，并启用随模型附带的 Local Head，把边界从模型的 80 ms 时间网格细化到 10 ms。CTC 仍可在设置里选用；文稿匹配固定用 CTC。
- **对齐模型改名、换目录**：现在下载为 `Qwen3-ForcedAligner-Ultra`。旧 `settings.json` 里的选择、以及写在 `Qwen3-ForcedAligner-0.6B-hf` 名下的每个模型目录会自动迁移；旧目录不再使用，Ultra 权重在第一次打轴时下载（约 1.8 GB）。
- **长队列不卡**：任务列表改用虚拟化并自绘右侧滚动条，完成的任务再多也不会为每一行都建一个控件。
- **成功任务保留日志**：完成的任务会滚动保留一份日志，但不往任务行里塞噪音；事后排查仍拿得到。
- **盲切落在能量最低点**：没有足够长的停顿时，切点落在能量最低处，不再随便切一帧；停顿门槛抬到 1 ms。

## 修复

- **文稿美化正确处理分号**：分号和其他句末标点一样收成一个空格。
- **换模型时下载进度不再一开始就 100%**：尺寸对不上的旧成品不再被算成已下载字节，进度条反映真正在下的量。
