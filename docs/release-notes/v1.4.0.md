# OneAsr 1.4.0 — your script stays your script, steadier long-audio runs

## New

- **Transcript matching keeps your text verbatim**: every cue is the line you wrote, with its spaces, full-width spaces and punctuation untouched; alignment only adds timestamps. Beautifying now happens on the script before alignment (`transcript polish`), never after it.
- **Repeated / runaway chunks are rescued**: when a chunk makes the recognizer loop or hit the token limit, it is cut in half and retried (up to three levels). If it still degenerates you get a warning instead of silently missing lines. This applies to every run, not only hotword runs.
- **Cuts land in a pause**: voice detection now picks up 100 ms gaps and prefers a breath pause before cutting at the target length, so fewer cuts land inside a word.
- **The CLI reads settings.json**: `transcribe` / `align` / `status` / `download` use the model folders you configured in the GUI; explicit flags still override. New `download` (fetch a model without opening the app), `status` (model readiness, resolved folders, start gate), `probe` (size / duration / media kind) and `transcript inspect|split|polish`; `--events=json` prints one JSON event per line.
- **More formats in the Add dialog**: the media picker now offers the same 20 audio/video extensions as drag-and-drop, including FLV, TS, MPEG, MPG, WMV and 3GP; transcript pairing uses that same table.

## Fixed

- Smart segmentation only moves line breaks: spacing inside a line is preserved instead of being re-joined word by word.
- A configured model folder that is temporarily unavailable stays configured instead of being silently reset to the install layout.
- **Windows**: verifying large model weights no longer crashes with a stack overflow — the 1 MiB read buffer is now allocated on the heap.
- `probe` no longer reports a `.txt` file as audio.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash

```

2. Or right-click 安装 OneAsr.command → "Open" → "Open" again in the dialog.

# OneAsr 1.4.0 — 文稿原样出字幕，长音频更稳

## 新增

- **文稿匹配原样保留你的文字**：每条字幕就是文稿里的那一行，空格、全角空格与标点一个不动，对齐只补时间轴。美化提前到打轴之前、作用在文稿本身（`transcript polish`），打完轴不再改字。
- **复读 / 撞顶的块会救回来**：某个分块让识别陷入复读或撞到 token 上限时，对半切开重解（最多三层）；仍然退化会给出告警，而不是静默丢掉整段台词。所有任务都走这条，不只热词任务。
- **切点优先落在换气处**：语音检测能识别 100ms 的缝隙，按目标时长切之前先找呼吸停顿，切在词中间的情况明显减少。
- **CLI 读取 settings.json**：`transcribe` / `align` / `status` / `download` 使用你在界面里配置的模型目录，显式旗标仍可覆盖。新增 `download`（不打开界面也能下模型）、`status`（模型就绪、解析后的目录、开跑门禁）、`probe`（大小 / 时长 / 媒体类型）与 `transcript inspect|split|polish`；`--events=json` 每行输出一个 JSON 事件。
- **添加对话框支持更多格式**：媒体选择器与拖放使用同一张 20 项扩展名表，FLV、TS、MPEG、MPG、WMV、3GP 现在都选得到；文稿配对也用这张表。

## 修复

- 智能断句只动换行：行内字距原样保留，不再被逐词重拼掉。
- 配置过的模型目录暂时不可用时，保持配置不变，不再被静默改回安装布局。
- **Windows**：校验大模型权重不再因栈溢出崩溃——1 MiB 读取缓冲改到堆上分配。
- `probe` 不再把 `.txt` 报成音频。
