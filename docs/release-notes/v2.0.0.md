# OneAsr 2.0.0 — Electron interface, transcript matching

> **Preview build** — this is the first release on the Electron line and is marked as a pre-release on GitHub. Please report any problems you run into; the stable GPUI release remains available on the releases page.

This release replaces the desktop shell with a new Electron interface while keeping everything local and offline. The speech engine, models and subtitle pipeline are the same CLI underneath.

## New

- **New Electron interface**: a light, single-window UI with a task list, settings, hotwords, statistics and a built-in guide. The interface switches between Chinese and English immediately without restarting.
- **Transcript matching**: drop a `.txt` or `.srt` with the media (same file stem), or drop a transcript onto an existing task. One transcript line becomes one subtitle line; an SRT's own timings are ignored and re-aligned with the CTC aligner.
- **Transcript panel**: view line and character counts, a speech-rate check, and edit the text with line numbers; line numbers are subtitle numbers. Smart sentence splitting, re-read from the source file and remove are available. The source transcript is never modified; the result is written as `<name>.aligned.srt`.
- **Model paths per model**: ASR 0.6B / 1.7B (fp16 and int8), the CTC / Qwen aligner, Demucs and SenseVoice each remember their own directory. Switching size or engine no longer overwrites another model's path.
- **In-app model downloads**: download any model from Settings → Models, with progress shown on its path row. Models download independently, so several can run at once. While a model downloads, its path field itself fills with progress instead of showing a separate thin bar. A model already present and verified is never downloaded again; downloads go to the path shown for that model.
- **Task controls**: start, cancel, start all, remove or clear the list; each row can set its recognition language, hotword group and vocal separation, and apply those settings to all other rows. Completed rows open their output folder directly.
- **Settings**: output formats (SRT / TXT / ASS), Chinese script and subtitle beautification, subtitle length and chunk length, output directory or "save next to the source", inference backend, sound and close-to-tray.
- **Package layout**: Windows installer / portable build, Linux `.deb` / portable `.tar.gz`, and an Apple Silicon `.dmg`. Models and settings (and the output folder when you do not save next to the source) live in the data directory next to the app when that folder is writable; read-only installs (Linux `/opt`, macOS `.app`) use the platform user-data directory automatically.

## Fixed

- The titlebar now blends with the system window controls, and the divider below them is no longer cut off.
- Dialogs now open below the titlebar, so the system window controls no longer cover their top-right corner.
- Settings shows only labels, status, and controls; the model-path explanation now lives in Guide → Models.
- Model rows show a download icon when the model is missing, and the re-download icon only when it is already available.
- Re-downloading an installed model only shows the download state when verification actually takes a moment; a quick check no longer makes the row jump.
- After a model download finishes, its row switches to Re-download immediately; deleting the model and refreshing switches it back to Download.
- All confirmations now use the same centered card, including unsaved changes and clearing the task list; the task list no longer opens a popover under the toolbar.
- The cancel button's tooltip stays visible while a download runs; it no longer flickers as progress changes.
- Cancelling a running task now stops the whole child process tree, including ffmpeg, instead of leaving it running in the background.
- A task that is cancelled while its start check is still running no longer starts afterwards.
- TXT-only output no longer requires the alignment model.
- The subtitle-length setting and the Chinese-script setting now apply to normal transcription and transcript matching respectively.
- Hotword groups can only be chosen on Chinese and English rows; other languages show No hotwords and cannot pick a group. A default group with no words is no longer attached to new tasks, and an unnamed group no longer shows as a blank chip.
- Guide → Hotwords now explains how to enter words, which separators work, how duplicates are merged, and includes an example.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 2.0.0/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 2.0.0 — Electron 界面与文稿匹配

> **预览版** —— 这是 Electron 线的第一个版本，在 GitHub 上标记为预发布（pre-release）。遇到问题欢迎反馈；稳定的 GPUI 正式版仍可在 Releases 页面下载。

这一版把桌面壳换成了新的 Electron 界面，仍然全程本地、离线运行；底层的识别引擎、模型与字幕管线没有变，仍由同一个 CLI 驱动。

## 新增

- **新的 Electron 界面**：浅色单窗口，包含任务列表、设置、热词、统计与内置指南；中英文界面即时切换，不用重启。
- **文稿匹配**：把与媒体同名的 `.txt` / `.srt` 和媒体一起拖入，或把文稿拖到已有任务行。文稿一行就是一条字幕；SRT 自带的时间轴会被忽略，改用 CTC 对齐器重新打轴。
- **文稿面板**：显示行数、字数和语速检查；正文可编辑并带行号，行号就是字幕号。支持智能断句、从源文件重读和移除文稿。源文稿永远不会被改写，结果写成 `<文件名>.aligned.srt`。
- **每个模型独立路径**：ASR 0.6B / 1.7B（fp16 与 int8）、CTC / Qwen 对齐器、Demucs、SenseVoice 各记各的目录；切换尺寸或引擎不再覆盖另一个模型的路径。
- **应用内模型下载**：在「设置 → 模型」里下载任意模型，进度直接显示在对应路径行上。模型之间互不影响，可以同时下载多个。下载时路径框本身按进度填充，不再另开一条细进度条。已存在且校验通过的模型不会重复下载；下载落到当前显示的路径。
- **任务操作**：开始、取消、全部开始、移除、清空；每一行可以单独设置识别语言、热词组和人声分离，也可一键应用到其它行。完成的行可以直接打开输出目录。
- **设置**：输出格式（SRT / TXT / ASS）、中文字形与成稿字幕美化、字幕长度与分段时长、输出目录或「保存到源文件旁」、推理后端、提示音与关闭到托盘。
- **三平台产物**：Windows 安装包 / 便携包、Linux `.deb` / 便携 `.tar.gz`、Apple Silicon `.dmg`。可写的安装目录会把模型和设置（以及未勾选「保存到源文件旁」时的输出）放在应用旁；只读安装位置（Linux `/opt`、macOS `.app`）自动改用平台用户数据目录。

## 修复

- 标题栏与系统窗口按钮区颜色一致，按钮下方的分隔线不再被截断。
- 弹窗从标题栏下方开始，右上角的系统窗口按钮不再遮住面板。
- 设置页只保留标签、状态与操作，模型路径说明移到了「指南 → 模型」。
- 模型行只在模型已就绪时显示「重新下载」图标；缺失时显示普通下载图标。
- 对已安装模型点「重新下载」时，仅在校验确实耗时的情况下才显示下载状态，快速校验不再让整行跳动。
- 模型下载完成后，该行会立即变成「重新下载」；删除模型并刷新后变回「下载」。
- 所有确认统一成居中卡片（未保存关闭、清空任务列表等）；清空任务列表不再在工具栏下方弹出小卡。
- 下载中取消按钮的提示不再随进度刷新而闪烁。
- 取消运行中的任务现在会连同 ffmpeg 等后代进程一起收掉，不再把子进程留在后台。
- 启动检查还没返回时就取消的任务，不会在检查结束后又启动。
- 只输出 TXT 时不再强制要求对齐模型。
- 「字幕长度」和「中文字形」现在分别对普通转写与文稿匹配生效。
- 热词组只在中文和英文行可选；其它语言显示「无热词」且不能选。没有词的默认组不再自动绑到新任务，未命名的组也不会再显示成空白胶囊。
- 「指南 → 热词」补充了输入方法、分隔符、去重规则和示例。

## macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 用终端运行 —— 任何 macOS 版本都能用的方式：

```bash
bash "/Volumes/OneAsr 2.0.0/安装 OneAsr.command"
```

2. 想在访达里操作，就右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
