# OneAsr 1.5.1 — Open output location works on macOS

## Fixed

- **"Open output location" opens Finder on macOS**: the button was launching a Linux-only helper, so it failed without saying anything. It now asks Finder to reveal the subtitle file, and falls back to opening the folder that holds it.
- **A failed open is no longer silent**: on any platform, the status bar reports it and `oneasr-error.log` keeps the details, instead of leaving a button that appears to do nothing.
- **Linux without `xdg-open` still opens the folder**: the app falls back to `gio open`.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.5.1/安装 OneAsr.command"
```

2. Or right-click 安装 OneAsr.command → "Open" → "Open" again in the dialog.

# OneAsr 1.5.1 — macOS 打开输出位置修好了

## 修复

- **macOS 的「打开输出位置」真的会打开 Finder**：它之前调用的是只有 Linux 才有的 `xdg-open`，在 macOS 上直接失败、一句话也不说。现在由 Finder 定位并选中那份字幕文件，失败了再退回打开它所在的文件夹。
- **打不开不再没有反应**：任何平台上打不开文件管理器时，状态栏会给出提示，详细原因写进 `oneasr-error.log`，不再是一个点了没动静的按钮。
- **没有 `xdg-open` 的 Linux 也能打开**：改用 `gio open` 兜底。

## macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 用终端运行 —— 任何 macOS 版本都能用的方式：

```bash
bash "/Volumes/OneAsr 1.5.1/安装 OneAsr.command"
```

2. 或在访达里右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。
