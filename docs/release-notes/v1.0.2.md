## OneAsr 1.0.2 — 本地离线音视频转字幕

这一版把 ASR、强制对齐、人声分离三个引擎的底层库更新到最新优化版本。识别与对齐的结果和之前完全一致，处理速度全面提升，对齐模型的加载时间明显缩短。

### 新增

- **识别更快**：ASR 引擎更新到最新优化版本，prefill 与 decode 全链路均有可测量的提速，识别结果与之前逐位一致。
- **对齐更快**：强制对齐引擎更新到最新优化版本，模型加载时间大幅缩短；长音频的重采样、编码与首次对齐（含日语分词预热）也更快。
- **人声分离更快**：人声分离引擎更新到最新优化版本，分块推理流水线化并融合多个算子，同一段音频的分离耗时更短。

### macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 先右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」；
2. 如果 macOS 15 起把这条路拦了（弹框里只剩「完成」），改用终端：

```bash
bash "/Volumes/OneAsr 1.0.2/安装 OneAsr.command"
```

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
