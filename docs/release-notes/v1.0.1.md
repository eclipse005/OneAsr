## OneAsr 1.0.1 — 本地离线音视频转字幕

这一版集中在 **macOS 安装体验**，外加几处手上能直接感觉到的修复。

### 新增

- **耗时弹卡显示倍速**：把鼠标悬停在任务行的「用时」chip 上，弹卡第一行右侧会显示这一次处理的倍速（音视频时长 ÷ 处理耗时），与旁边的总耗时互为倒数、可互相验算。统计面板里同源的「平均速度」「最快一次」也统一成「倍速」的说法。

### 修复

- **macOS 标题栏**：改用系统红绿灯，不再自绘 Windows 风格的最小化/最大化/关闭（那三个按钮在 macOS 上点了没有任何反应）；标题栏左侧留出空间，版本号不再被红绿灯压成 `0.0`。
- **每个 ASR 尺寸各记一个模型目录**：以前把模型指到自定义目录后，只要切一次 0.6B / 1.7B，路径就被重置回安装目录。现在两个尺寸各自记住自己的路径，同一根目录下的兄弟文件夹也会自动认出来，不用再手动选一次。
- **构建警告清零**：修掉自有代码 1 条、vendored gpui 2 条警告（其中两条是 future-incompatible，未来 Rust 版本会变成硬错误）。

### macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 先右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」；
2. 如果 macOS 15 起把这条路拦了（弹框里只剩「完成」），改用终端：

```bash
bash "/Volumes/OneAsr 1.0.1/安装 OneAsr.command"
```

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
