# OneAsr 1.4.2 — DX12 loads in seconds

## New

- **DX12 path optimised**: the Windows package now ships its own shader compiler, so a machine that cannot use Vulkan goes from ~17 minutes of first-load compiling to seconds.

## Fixed

- **Script files are read by their own encoding**: BOM / UTF-8 / GB18030 transcripts are no longer silently turned into mojibake.
- **A script that fails to open now says why**, instead of leaving the row stuck.
- **`align` rejects a non-CTC aligner directory up front** instead of failing later with a config-parse error that points at the wrong thing.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.4.2/安装 OneAsr.command"
```

2. Or right-click 安装 OneAsr.command → "Open" → "Open" again in the dialog.

# OneAsr 1.4.2 — DX12 加载降到秒级

## 新增

- **DX12 路径优化**：Windows 包内自带着色器编译器，用不了 Vulkan 的机器首次加载从十几分钟降到秒级。

## 修复

- **文稿按自身编码读取**：带 BOM / UTF-8 / GB18030 的文稿不再被静默读成乱码。
- **文稿打不开时会说清原因**，不再让那一行一直卡着。
- **`align` 会当场拒绝非 CTC 的对齐器目录**，不再走到一半报一个指错方向的 config 解析错误。

## macOS 安装

包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统隔离标记，装好之后不再提示。磁盘映像里附了「安装说明.txt」和「安装 OneAsr.command」：

1. 用终端运行 —— 任何 macOS 版本都能用的方式：

```bash
bash "/Volumes/OneAsr 1.4.2/安装 OneAsr.command"
```

2. 或在访达里右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」。
