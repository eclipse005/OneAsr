# OneAsr 1.2.0 — local, offline audio/video → subtitles

This release adds **transcript matching** — align an existing script instead of transcribing — plus **ASS karaoke subtitles** and a fully bilingual interface.

## New

- **Transcript matching**: attach a `.txt` / `.srt` script to the media and recognition is skipped entirely — the aligner measures a real timestamp for every line you wrote and produces the subtitle. Correct the mis-heard words in any text editor first, then match; what you write is what airs. Matching outputs are named `video.aligned.srt`.
- **ASS karaoke subtitles**: a third output format in Settings (CLI `--ass`). CJK characters — and words in spaced languages — each carry their own sweep timing, so players can highlight the text while it plays.
- **Optional CTC aligner**: omniASR-CTC-300M-v2 joins the Qwen ForcedAligner; pick the aligning engine in Settings.
- **Live alignment progress**: the aligning stage now reports the aligner's own window progress instead of standing still.
- **Transcript card on every task row**: hover to peek, click to pin. "Smart break" splits only over-long lines and never changes a character, and the original file is never written. While a task is queued or running, the transcript actions lock so nothing changes under the pipeline.
- **Bilingual interface**: every UI label and pipeline message comes in English and Chinese, following the system language with a manual override. The macOS install notes and install script are bilingual too.
- **Stats panel counts transcript matches**, and GUI runs no longer leave a `timeline.json` beside your subtitles — the CLI writes one on request, and `oneasr-cli render` re-renders it into another preset without loading any models.
- **GPU selection you can trust**: pin one card with the `ONEASR_DEVICE` environment variable — a bad name is an error, not a silent detour to another GPU; `auto` walks discrete GPU → integrated GPU → CPU inside the engine; the log states the actual backend and device used.

## Fixed

- Transcript matching can no longer overwrite your own subtitles: outputs always go to `video.aligned.*`, even when the script sits next to the video. A match with only TXT enabled stops with a clear message instead of producing a file without timestamps.
- The transcript hover card could never open — hover, click and the file-picker paths all failed to light it up; it also stays anchored to its own row.
- Japanese subtitles no longer split the sentence-final particles な / なあ into their own cue or glue them onto the next line.
- Linux `.deb` installs could not download models (read-only install directory → Permission denied). Models, output and stats now go to the user data directory when the install location is not writable; portable installs keep data next to the executable as before.
- Downloading a model after picking a custom directory no longer writes the bytes to the default directory while the UI points at the empty one you chose.

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.2.0/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 1.2.0 — 本地离线音视频转字幕

这一版上线 **文稿匹配**——已有文稿就跳过识别直接打轴——外加 **ASS 卡拉OK字幕**，界面全面双语。

## 新增

- **文稿匹配**：给音视频挂一份 `.txt` / `.srt` 文稿，完全跳过识别——对齐器给你写的每一行量出真实时间轴、直接出字幕。识别错的字先在任意文本编辑器里改好再来匹配，写什么上什么。匹配输出固定叫 `视频名.aligned.srt`。
- **ASS 卡拉OK字幕**：设置里第三个输出格式（CLI `--ass`）。中日韩逐字、空格语言逐词，每个单元自带扫光时间，播放器可以跟着做逐字高亮。
- **对齐器可选**：omniASR-CTC-300M-v2 与 Qwen ForcedAligner 并存，设置里选择用哪个对齐引擎。
- **打轴进度动起来**：对齐阶段现在显示对齐器自己的窗口进度，不再是干等。
- **每个任务行都有文稿卡片**：悬停预览、点击粘住。「智能断句」只拆过长行、一个字都不动，原文件不会被写入。任务排队或运行中，文稿操作自动锁定，避免管线读着的东西被改掉。
- **界面双语**：所有界面标签与管线消息都有中英两份，跟随系统语言、也可手动切换。macOS 的安装说明与安装脚本同样双语。
- **统计面板新增「文稿匹配」计数**；GUI 运行不再在字幕旁边遗留 `timeline.json`——CLI 需要时可写出，并用 `oneasr-cli render` 免加载模型重渲染成其它预设。
- **显卡选择可信**：用 `ONEASR_DEVICE` 环境变量钉死一张卡——名字写错直接报错，不会悄悄改去别的卡；`auto` 由引擎内部按独显 → 集显 → CPU 的顺序走；日志写明实际使用的后端与设备。

## 修复

- 文稿匹配不会再覆盖你自己的字幕：输出一律写到 `视频名.aligned.*`，哪怕文稿就放在视频旁边。只开 TXT 就发起匹配会停下并给出明确提示，而不是产出一个没有时间轴的文件。
- 文稿悬停卡片从来没被打开过——悬停、点击、选完文件三条路全断；现在也会固定锚在自己的行上。
- 日语字幕不再把句尾助词 な / なあ 单独切一条、或者粘到下一句开头。
- Linux `.deb` 安装后无法下载模型（安装目录只读 → Permission denied）。安装位置不可写时，模型、输出与统计现在落到用户数据目录；便携包依旧数据在程序旁边。
- 手选了自定义模型目录再点下载，不再出现字节写进默认目录、界面却指向你选的空目录的情况。

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
