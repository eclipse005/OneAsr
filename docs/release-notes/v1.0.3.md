## OneAsr 1.0.3 — Linux 标题栏与原生提示音

这一版保持现有安装包、便携包和下载使用方式不变，重点修复 Linux 标题栏操作，并让提示音通过系统音频设备直接播放。

## 新增

- **Linux 原生提示音**：提示音改为进程内通过系统音频输出播放，Linux 使用 ALSA，不再依赖外部播放器进程。

## 修复

- **Linux 标题栏操作**：修复 Wayland / X11 下标题栏拖动和窗口按钮无响应的问题，最大化、还原、最小化和关闭操作恢复正常。
