## OneAsr 1.0.3 — Linux 标题栏与原生提示音

这一版保持现有安装包、便携包和下载使用方式不变，重点修复 Linux 标题栏操作，并让提示音通过系统音频设备直接播放。

## 新增

- **跨平台原生提示音**：Windows、macOS、Linux 统一使用系统音频输出；Linux 使用 ALSA，macOS 使用 CoreAudio，Windows 使用 WASAPI。

## 修复

- **Linux 标题栏操作**：修复 Wayland / X11 下标题栏拖动和窗口按钮无响应的问题，最大化、还原、最小化和关闭操作恢复正常。

## macOS 安装

macOS 包未签名（没有 Apple 开发者账号），首次安装需要解除一次系统的隔离标记。磁盘映像里附有「安装说明.txt」和「安装 OneAsr.command」：

1. 先右键「安装 OneAsr.command」→ 选「打开」→ 弹框里再点一次「打开」；
2. 如果 macOS 15 起把这条路拦了（弹框里只剩「完成」），改用终端：

```bash
bash "/Volumes/OneAsr 1.0.3/安装 OneAsr.command"
```

（终端里敲 `bash` 加一个空格，然后把脚本图标拖进终端窗口，路径会自动补上。）
