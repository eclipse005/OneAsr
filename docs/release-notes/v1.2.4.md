# OneAsr 1.2.4 — vocal separation memory and subtitle cuts

## Fixed

- With vocal separation on, long audio no longer grows host RAM without bound during Demucs streaming (issue #17).
- Subtitle line cuts inside the length budget also use soft clause punctuation and strong silence, not only hard sentence ends.
- When a cue is over budget, the forced split prefers clause punctuation and avoids cutting after particles, genitives, and coordinators; Korean Hangul is aligned by word (eojeol) spacing.

# OneAsr 1.2.4 — 人声分离内存与字幕切句

## 修复

- 开启人声分离时，长音频在 Demucs 流式处理中不再让本机内存无限增长（issue #17）。
- 字幕行在长度预算内切分时，也会用软从句标点和强静音，不只依赖硬句末。
- 超预算强制切分时优先从句标点，并避免在助词、属格、连词后切开；韩语 Hangul 按词（语节）空格对齐。
