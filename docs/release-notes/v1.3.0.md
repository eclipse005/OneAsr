# OneAsr 1.3.0 — hotwords, a roomier word list, cleaner Japanese line breaks

## New

- **Hotwords (optional)**: bind a word list to a task and the words that matter come out right — a lightweight model runs a first pass, recalls the entries it hears, and hands them to the ASR model as context; phonetic matching covers what the first pass mishears, so a list only needs the correct spelling. Lists are managed as groups on a new hotword page (model download, groups, word editing; a switch decides whether newly added tasks use the default group, and each task can override it in its row). The hotword model is a separate ~940 MB download.
- **Chinese and English transcription only**: hotwords match Chinese (pinyin) and English (spelling) pronunciation only, so other languages skip the hotword pass entirely — their rows show the hotword picker grayed out, with the reason on hover, and tasks with no group never touch the hotword model.
- **Text fields**: drag to select; undo / redo with Ctrl+Z, Ctrl+Y (Ctrl+Shift+Z also redoes); the selection highlight is actually visible on Ctrl+A. Word lists wrap at commas — no more half-empty line ends — and Latin words are no longer split in the middle.
- **Japanese line breaks**: Japanese CTC alignment units are regrouped into words, so subtitles no longer break inside a word.

## Fixed

- Blocked by hotwords (a group with no words, or the hotword model missing), the app now opens the hotword page — where those can actually be fixed — instead of Settings.
- Unnamed hotword groups show localized placeholder names (Default / Untitled) instead of machine ids like `default` or `g1`.
- The word-list box fills the drawer's remaining height, so a maximized window no longer leaves a blank area under the box.
- Stage names are now consistent throughout (Extracting hotwords / Transcribing / Aligning).

## macOS Install

The package is unsigned (no Apple Developer account), so the first install needs the system's quarantine mark cleared once; afterwards there are no prompts. The disk image includes 安装说明.txt and 安装 OneAsr.command:

1. Run it in Terminal — the method that works on every macOS version:

```bash
bash "/Volumes/OneAsr 1.3.0/安装 OneAsr.command"
```

2. If you prefer Finder, right-click 安装 OneAsr.command → choose "Open" → click "Open" again in the dialog.

(In Terminal, type `bash` plus a space, then drag the script icon into the Terminal window — the path fills in automatically.)

# OneAsr 1.3.0 — 热词、更好用的词表框、日语断句更干净

## 新增

- **热词（可选）**：给任务绑一份词表——先用轻量模型转一遍、召回其中的热词，再作为上下文交给识别模型；音素模糊匹配兜住这一趟听错的字，所以词表只写正确写法。词表按组管理（热词页：模型下载、组管理、词表编辑），页面里有一个开关决定新加入的任务是否默认用热词，任务行里也可逐个任务改。热词模型要另下（约 940 MB）。
- **仅中文与英文的转录使用热词**：音素匹配只有中文（拼音）与英文（拼写）两套规则，其他语言整趟跳过——任务行里的热词选择器置灰、悬停说明原因；没绑组的任务完全不碰热词模型。
- **文本输入框**：支持拖选；Ctrl+Z 撤销、Ctrl+Y（或 Ctrl+Shift+Z）重做；Ctrl+A 的选区高亮真正可见。词表按逗号折行，行尾不再留半行空白；拉丁词不再从中间劈开。
- **日语断句**：CTC 的日语音素单元按词重分组，字幕不再切在词内。

## 修复

- 被热词挡住开跑（组没词 / 热词模型缺失）时，界面翻到热词页（问题能在那里修），不再一律翻设置页。
- 没起名的热词组显示本地化占位名（「默认」/「未命名」），不再显示 `default`、`g1` 这类机器 id。
- 最大化窗口时词表框长满抽屉剩余高度，不再在框下留一大片空白。
- 阶段名统一为「热词提取 / 转写 / 打轴」，与「分段规划」等同一种说法。
